# 星广联投产品考核分数

在用户指定的浏览器中读取服务商首页「星广联投任务 → 考核与权益 → 产品数据情况」，以页面当前显示的产品考核卡片为来源。周期、产品清单、账号和指标值都是本次输入，不沿用过去的数值。

1. 使用 Computer Use 找到用户已登录的巨量星图服务商首页（`https://www.xingtu.cn/provider/index`）。若用户指定 Edge，使用 Edge。先确认选中的周期类型、投放周期、数据更新时间及产品按钮清单。用户未指定其他范围时，使用页面当前选中的范围；如用户指定其他周期，按页面控件选择并逐一记录。
2. 逐个点击产品，确认卡片已切换并加载，再读取该产品所有考核卡片。逐卡记录页面展示的当前得分、各指标值及各项得分，包括素材目标达成率、考核目标数、提案素材数、KOC 平均 ARPU、素材高分率、创意方向数和负分指标；页面实际字段变化时以页面为准。多张卡片各占一行并保留页面顺序；没有明确身份标签时，用「卡片顺序」标识，不推断任务、载体或合并卡片。缺失、加载失败和页面的 `-` 保持原状，不当成 0。
3. 平台「导出数据」可作辅助，但先核对其投放周期、数据统计时间和指标口径。历史导出不能替代当前页面数据；不要仅因导出表首行显示旧周期，就推断其全表范围。
4. 以用户给的表格为结构参考，创建飞书电子表格，逐行包含产品、卡片顺序、总分、指标和分项得分、周期及更新时间。数值和百分比保留数值类型及页面显示精度。说明卡片顺序只是页面顺序，不是任务身份。用户未要求时不修改既有表或分享权限。使用飞书 `lark-cli` 的 `lark-shared` 和 `lark-sheets` 技能，按当前版本说明创建及回读。
5. 核对产品清单、每产品卡片数、首末行及全表回读与采集数据；核对分项得分之和与显示总分，若不一致保留页面原值并说明。若有无法读取的产品或字段，明确列出，不声称全量完成。返回可点击的飞书链接、周期、更新时间和重要限制。
