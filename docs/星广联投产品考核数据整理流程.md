# 星广联投产品考核数据整理流程

## 用途和范围

从巨量星图服务商首页的「星广联投任务 → 考核与权益 → 产品数据情况」采集各产品的考核指标和分数，整理为飞书电子表格。周期类型、投放周期及产品清单以本次请求和页面显示为准；未指定时使用页面当前选中的周期。

## 操作步骤

1. 使用用户指定的浏览器打开已登录的服务商首页，记录周期类型、投放周期、数据更新时间和全部产品名称。
2. 逐个点击产品，等待页面更新，读取该产品下每张考核卡片的当前得分、指标值和各项得分。页面可能出现多张卡片：每张单独占一行，保留页面显示顺序；若没有身份标签，不推断其对应任务或载体。
3. 包含页面可见的素材目标达成率、考核目标数、提案素材数、KOC 平均 ARPU、素材高分率、创意方向数、负分指标及对应得分；页面字段变化时以实际显示为准。缺失、读取失败及页面显示的 `-` 不应改为零。
4. 如参考平台导出数据，先核对投放周期、统计时间及指标口径。历史记录不得直接替代当前页面；不能只凭导出表首行判断整张表的范围。
5. 创建飞书电子表格，按产品及卡片顺序逐行记录指标、得分、周期与更新时间。数值及百分比保留为数值类型。注明卡片顺序仅表示页面顺序。
6. 核对产品清单与卡片数量，检查分项得分和页面总分；发生差异时保留原值并说明。回读飞书表格的全部数据，与采集记录逐项比对。报告飞书链接、周期、更新时间和未能核实的项目。

## 配套技能

仓库中的 `skills/xingtu-provider-scores/SKILL.md` 为 Codex 可复用技能。将该技能目录放入 Codex 的技能目录后，可请求 Codex 按此流程整理当前或指定周期的产品考核数据。技能文件不包含登录凭证、录制记录或实际分数。
